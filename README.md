# Plan de Medios — Brainworks Diseño

Sistema de marketing digital para [brainworks.cl](https://brainworks.cl), tienda/oficina de diseño de mobiliario interior y exterior (importación de marcas europeas: Italia, España, Portugal, Holanda), con showroom en El Golf/Vitacura, Santiago, y venta tanto a clientes finales (retail/deco) como a arquitectos, diseñadores de interior y proyectos de alto tráfico (hotelería, restaurantes, inmobiliario).

Este repositorio documenta el plan de medios y el "sistema" operativo (pilares de contenido, cadencia, estructura de campañas, KPIs y flujo de trabajo) para tres canales:

1. **[Instagram](plan-de-medios/01-instagram.md)** — canal principal de marca y demanda B2C (@brainworks_diseno).
2. **[LinkedIn](plan-de-medios/02-linkedin.md)** — canal B2B para arquitectos, interioristas, inmobiliarias y proyectos contract/hospitality.
3. **[Google Ads](plan-de-medios/03-google-ads.md)** — captura de demanda de búsqueda activa (Search, Shopping/PMax, Display remarketing, Local).

También incluye:

- **[Audiencias y objetivos](plan-de-medios/00-audiencias-objetivos.md)** — buyer personas, objetivos SMART y el embudo común a los tres canales.
- **[Presupuesto, KPIs y calendario de implementación](plan-de-medios/04-presupuesto-kpis-calendario.md)** — distribución de inversión sugerida, tablero de métricas y roadmap a 90 días.

> Los montos de presupuesto son una referencia inicial de distribución porcentual; deben ajustarse al presupuesto real disponible y revisarse mes a mes con datos reales de rendimiento.
